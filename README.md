# Homework_Python

Репозиторий с домашними заданиями по автоматизации тестирования на Python (Pytest + Allure).

## Структура проекта

- `lesson_10/` — папка с заданиями 10-го урока.
  - `test_calculator.py` — тесты для калькулятора.
  - `test_shop.py` — тесты для интернет-магазина.
- `allure-results/` — (игнорируется git) папка с сырыми данными для отчёта Allure.
- `allure-report/` — (игнорируется git) папка с готовым HTML-отчётом.

---

## Как запустить тесты

Для запуска всех тестов в проекте используй следующую команду в терминале (убедись, что ты находишься в корне проекта `Homework_Python`):

```bash
pytest
